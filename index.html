Vibe Farmer Help

OpenAI WebMCP Challenge

Vibe Farmer is a challenge entry about human-agent collaboration on the open web. You and an AI-controlled robot share one farm, one economy, and the same basic actions.

About the challenge

WebMCP

WebMCP lets a compatible browser expose website-defined tools to an AI agent. Here, those tools let an agent inspect the farm and control the robot with visible, single-step actions.

Status: Checking this browser...

Open this page in the ChatGPT desktop app and use its in-app browser, which supports WebMCP. Alternatively, install Google Chrome 149 or later, enable WebMCP for testing at chrome://flags/#enable-webmcp-testing, and restart Chrome.

You can still play normally and test every robot tool in Robot Inspector without WebMCP.

  1. Open this page in a WebMCP-capable browser.
  2. Ask the browser's agent to inspect the game and help run the farm.
  3. Open Robot Inspector to see its tools, view, operations, and logs.
